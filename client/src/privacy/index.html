プライバシーポリシー

Yuniview 公式サービス · 第1版 · 2026年11月22日制定

サービスの利用

運営者が管理するサービスの稼働状況を調べるため、接続したサービスからメトリクス、ログ、トレースなどを受信します。管理画面と MCP の利用には Cloudflare Access による認証を使用します。運営者はこれらの記録を障害の調査、ダッシュボードの表示、モニターの評価に利用します。

管理者の利用状況

ログインした管理者のアカウント数を日本時間の日ごとに集計します。認証時に検証したアカウントの識別子を、サービス専用の鍵と日付を使って変換し、同じ日の重複を除きます。集計用の識別値は自営の Yuniview に直近30日分を保存します。この値で日をまたいだアカウントの照合や月間UUの計測は行いません。

接続元サービスの日別集計

接続元が日別の利用者数を計測する場合、Yuniview はサービス名、対象日、識別子の種類、サービス側で日別に変換した値を受け取り、直近30日分を保持します。対象がブラウザかログインアカウントかは、各サービスのプライバシーポリシーで確認できます。

接続情報と運用ログ

サイトの配信・保護のため、Cloudflare と本サービスのサーバーが IP アドレス、アクセス日時、リクエスト先などの接続情報を処理します。運営者はサービスの状態を監視し、障害や不正利用を調べるために運用ログや稼働状況を確認します。
