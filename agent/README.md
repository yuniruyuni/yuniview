# yuniview agent の統合仕様案

agent は yuniview がバージョン付き OCI イメージとして配布する収集プロセス。単独起動や Compose からも利用できる設計とする。現段階は仕様案で、実行イメージは今後実装する。

起動側は取り込み先、送信資格のファイル、サービス・ワークロード・インスタンスの識別情報、収集する信号を渡す。blue/green の slot と revision は任意の属性。agent は OTLP/gRPC を受信し、対象に限定して公開されたログ・cgroup を読み、中央へバッチ送信する。中央は送信資格と送信元を照合する。

yunirun の統合は次の段階で行う。通常の配布物に telemetry 宣言を解釈して sidecar を構成する能力を含め、ホストが使用する agent のバージョンを選び、宣言した workload に起動する。起動側との契約はイメージ・設定・通信仕様とし、両製品は別々にリリースする。
